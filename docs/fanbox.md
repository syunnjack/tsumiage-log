# pixivFANBOX（月額の継続支援）

BOOTHと同じpixivアカウントで始められる、月額支援の受け皿です。
単発の購入（BOOTH）や記事単位の支援（codoc）と違い、**毎月続く収入**になります。

## 有効にする手順

### 1. FANBOXを開設する

[fanbox.cc](https://www.fanbox.cc/) にpixivアカウントでログインし、
クリエイターページを作ります。BOOTHと同じアカウントなので新規登録は不要です。

### 2. 環境変数を設定する

```env
NEXT_PUBLIC_FANBOX_URL=https://<あなたのID>.fanbox.cc
```

**未設定のあいだは `/store` にFANBOXのカードが出ません。** 開設前にリンクだけ
置くと、踏んだ人が行き止まりに当たるためです。

## プラン案

技術ブログの支援としては、金額を分けすぎない方が選びやすくなります。
3段階までを目安にした案です。

### 300円／月：開発の記録を読む

- 記事や動画にする前の**途中経過**を月2〜3回投稿
- うまくいかなかった試行錯誤も含めて公開（公開記事には書きにくい失敗の記録）
- 支援者限定の短いメモ

### 800円／月：作ったものを使う

- 上記すべて
- 買い切りで販売しているツールを**支援中は自由に使える**
- 新しいツールを公開前に試せる

### 3,000円／月：相談する

- 上記すべて
- 月1回、実装や構成について**個別に質問できる**枠
- 「この構成で作りたい」への具体的な回答

## 何を投稿するか

すでに147本の動画と多数の記事という素材があるので、FANBOX用に新しく作る
必要はありません。**公開物の裏側**を出すのがいちばん無理がありません。

- 記事にする前の調査メモ（例：GA4の調査で試して外した方法）
- 動画の制作過程（ナレーション原稿、レンダリングの詰まり）
- 収益の実数値（アドセンス、BOOTH、アフィリエイトの推移）
- 失敗の記録（作ったが伸びなかったサイトとその理由）

最後の2つは、同じことをしている人にとって最も価値があり、かつ公開の場では
書きにくい内容です。支援の理由になりやすいところだと思います。

## 実装の場所

| ファイル | 役割 |
|---|---|
| `app/lib/store-links.ts` | FANBOXのURL。環境変数で設定する |
| `app/store/page.tsx` | `/store` のカード。未設定なら出さない |
| `app/globals.css` | `.store-channel-fanbox` の見た目 |

## 手数料

FANBOXの手数料は支援額に対して差し引かれます（プラットフォーム手数料と
決済手数料）。最新の料率は[FANBOXのヘルプ](https://help.fanbox.cc/)で
確認してください。
